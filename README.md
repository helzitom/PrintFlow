
# PrintFlow

Sistema de gestión y automatización de pedidos de impresión.

## Descripción

PrintFlow permite recibir documentos mediante WhatsApp,
gestionar pedidos, aprobar impresiones remotamente y
ejecutar trabajos mediante una impresora conectada
físicamente a una computadora Windows.

## Arquitectura

- Backend: ASP.NET Core Web API.
- Arquitectura: Clean Architecture.
- Integración WhatsApp: Node.js.
- Aplicación de escritorio: C# .NET.
- Aplicación móvil: React Native + Expo.
- Base de datos: PostgreSQL.
- Notificaciones: Firebase Cloud Messaging.
